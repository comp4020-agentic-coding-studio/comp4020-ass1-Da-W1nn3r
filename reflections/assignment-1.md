1. What was the breakthrough that moved the work forward?
Initally structuring the project and emphisising that I wanted a framework for the project rather than telling it to write the project in one shot was much more effective for this larger project. By splitting this project into making a framework for the graphics and researching information to put in the framework resulted in a much easier system to edit and fix. 

2. What did this work change about who I want to be as a software developer?
Dividing the project into smaller parts allows for saving token by clearing sessions and smoother development with agentic coding agents. I do think creating documentation and specifying tasks to be divided between different instances of the agent results in better projects.
